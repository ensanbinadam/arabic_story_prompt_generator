# حكاية — مولّد القصص المصوّرة التعليمية

أداة عربية تعمل بملف HTML واحد، تساعد المعلمين وصنّاع المحتوى على تحويل فكرة تعليمية أو نص مكتوب إلى مشروع قصة مصوّرة منظم: شخصيات ثابتة، ومشاهد متتابعة، ونصوص عربية، وبرومبت مستقل لكل صفحة.

**ملف التشغيل:** [`arabic_story_prompt_generator.html`](./arabic_story_prompt_generator.html)

**الإصدار الظاهر في الواجهة:** 1.1.

> «حكاية» محرر للمحتوى ومولّد للنصوص والبرومبتات. لا يتصل بخدمة ذكاء اصطناعي ولا يكتب القصة أو يولّد الصور تلقائيًا داخل الصفحة؛ تنسخ الطلب إلى المساعد أو أداة الصور التي تختارها، ثم تعيد المحتوى إلى المشروع.

## الميزات

- واجهة عربية باتجاه RTL، تتكيف مع أجهزة الحاسب والشاشات الصغيرة.
- مساران لإعداد المحتوى: تطوير فكرة إلى قصة جديدة، أو تنظيم نص مُدخل مع طلب الحفاظ عليه حرفيًا.
- إعداد الهدف التعليمي، والعمر، والصف الدراسي، ومستوى القراءة، والمفردات، والقيم، والأسئلة والتقويم.
- مشروع يضم من صفحة واحدة إلى **40 صفحة محتوى**، مع غلاف أمامي وخلفي اختياريين مستقلين.
- بطاقات لما يصل إلى **30 شخصية**، تتضمن الدور والعمر والملامح والملابس والإكسسوارات وأسلوب الكلام والمراجع.
- محرر صفحات للسرد والحوار والمشهد والشخصيات والتعلم والنشاط واللقطات وزاوية المشهد والمشاعر.
- إعادة ترتيب الصفحات وتكرارها وحذفها، وإخراج برومبت صفحة محددة.
- أنماط فنية متعددة، منها رسوم الأطفال، والكوميكس العربي، والألوان المائية، والقصاصات الورقية، والرسوم ثلاثية الأبعاد، والتلوين.
- خيارات للنص العربي والتشكيل والأرقام والفقاعات، وحماية النصوص المنقولة من التحريف.
- فصل إرشادات الرسم عن النص الذي يجب أن يظهر داخل الصورة.
- استيراد رد المساعد بصيغة نصية منظمة أو JSON، واستيراد مخطط صفحات مرقّم.
- حفظ المشروع في المتصفح، وتنزيل نسخة JSON، ومكتبة شخصية للقوالب مع الاستيراد والتصدير.
- قصص جاهزة للتجربة، ومؤشر اكتمال، وقائمة مراجعة لعناصر المشروع.

## التشغيل محليًا

1. نزّل `arabic_story_prompt_generator.html`.
2. افتحه في متصفح حديث مع تفعيل JavaScript.
3. اضغط **قصص جاهزة للتجربة** لاستكشاف الأداة، أو ابدأ بفكرة جديدة.

لا يحتاج المولد إلى تثبيت حزم أو عملية بناء أو مفتاح API أو خادم لتشغيله المعتاد. التنسيق والبرمجة مضمنان في الملف، والخطوط تأتي من الخطوط المتاحة على جهازك؛ لا يتضمن الملف تحميل مكتبات أو خطوط من شبكة خارجية.

إذا قيّد المتصفح الحافظة أو التخزين عند فتح الملف مباشرة، استخدم النسخ واللصق اليدويين، واحفظ المشروع بالتنزيل. يمكن أيضًا تشغيله عبر خادم محلي اختياري إذا كان Python مثبتًا؛ نفّذ الأمر التالي داخل مجلد المشروع:

</div>

```bash
python -m http.server 8000
```

## من فكرة إلى قصة مصوّرة

1. **فكرة القصة:** اكتب العنوان والموضوع، واختر تطوير فكرة أو الالتزام بالنص المُدخل، ثم حدد عدد الصفحات والمقاس والأغلفة.
2. **البناء التعليمي:** حدد العمر ومستوى القراءة والهدف ونوع الحكاية وبناء الأحداث وطريقة مشاركة القارئ. أضف النص المرجعي نفسه إذا كان المحتوى يعتمد على مصدر.
3. **الشخصيات الثابتة:** أضف بطاقات الشخصيات ووصف ملامحها وملابسها، واختر درجة الاتساق وطريقة استخدام المراجع.
4. **طلب كتابة القصة:** انسخ الناتج إلى مساعد ذكاء اصطناعي. يمكنك تفعيل **طلب نسخة JSON مع رد الذكاء** لتسهيل استيراده.
5. **استيراد رد الذكاء:** الصق الرد في نافذة الاستيراد، ثم راجع الشخصيات والصفحات والمعلومات والنصوص. ويمكن كتابة الصفحات مباشرة دون مساعد خارجي.
6. **الهوية البصرية والنص العربي:** اضبط أسلوب الرسم والألوان والإضاءة والهوامش ومواضع النص والفقاعات والتشكيل.
7. **برومبت الصور:** انسخ طلب القصة أو الدفعة، أو اختر **صفحة مستقلة** لنسخ برومبت صفحة أو غلاف.
8. **التوليد الخارجي:** أرفق صور الشخصيات أو الصفحة المرجعية داخل أداة الصور نفسها عند الحاجة، ثم نفّذ الطلب.
9. **المراجعة والحفظ:** راجع النص والرسوم والاتساق، ثم نزّل المشروع JSON وحزمة البرومبتات للاحتفاظ بالعمل.

**مثال سريع:** اختر «جسر التعاون»، وراجع الهدف والشخصيات والصفحات. افتح «صفحة مستقلة» وأنشئ الصفحة الأولى في أداة الصور، ثم استخدم صورتها المعتمدة مرجعًا لبقية الصفحات إذا اخترت هذا الأسلوب.

## المدخلات والمخرجات

### ما يمكن إدخاله

| المدخل | الغرض |
| --- | --- |
| فكرة ووصف مكتوب | تخطيط قصة جديدة |
| قصة أو نص حرفي | تنظيمه في صفحات مع طلب الحفاظ على عباراته |
| بطاقات شخصيات ومشاهد | إعداد المحتوى والاتساق يدويًا |
| نص مرجعي وبيانات مصدر | توجيه المحتوى التعليمي دون طباعته تلقائيًا |
| رد مساعد منظم | استيراد الصفحات والمحتوى من النص أو JSON |
| مشروع JSON | استعادة مشروع سابق |
| مكتبة قوالب JSON | نقل القوالب وإعادة استخدامها |

حقول المراجع البصرية تخزّن أوصافًا أو بيانات مرجع نصية. لا يوجد رفع للصور أو PDF داخل هذا المولد؛ أرفق الصور المطلوبة مباشرة في خدمة التوليد الخارجية. ذكر اسم صورة أو رابط مصدر لا يجعل الأداة تقرأ محتواه.

### ما تنتجه الأداة

| تبويب الإخراج | المحتوى |
| --- | --- |
| طلب كتابة القصة | طلب منظم للمساعد لإعداد القصة والصفحات والشخصيات |
| برومبت الصور | تعليمات الصور للقصة أو الدفعة أو الغلاف بحسب الإعدادات |
| صفحة مستقلة | برومبت لصفحة محددة أو غلاف أمامي أو خلفي |
| الممنوعات | قيود لغوية وبصرية ومحتوى غير مرغوب |
| المشروع JSON | بيانات المشروع القابلة للحفظ والاستيراد |

تتيح الأداة نسخ الناتج وتنزيله بصيغة TXT أو JSON بحسب التبويب. وتجمع **حزمة البرومبتات** طلب كتابة القصة وبرومبتات الصفحات والأغلفة المفعّلة في ملف نصي. ويمكن تنزيل مخطط القصة من محرر المشاهد.

الصور وملف PDF النهائي للقصة يُنتجان أو يُجمعان خارج هذه الصفحة؛ لا تصدّر الأداة كتابًا مصوّرًا أو PDF تلقائيًا.

## تحرير الشخصيات والصفحات

تسجل بطاقة الشخصية الاسم والدور والعمر والهيئة والملابس والأدوات وأسلوب الكلام والمرجع. اختر اتساقًا صارمًا جدًا أو صارمًا أو مرنًا، وأضف ثوابت المكان والألوان عند الحاجة.

تتضمن بطاقة الصفحة عنوانًا اختياريًا، ووصف المشهد، والسرد الظاهر، والحوار. وفي تفاصيلها يمكن تحديد الشخصيات والفكرة التعليمية وسؤال القارئ واللقطات والزاوية والمشاعر والمرجع.

عند كتابة الحوار، اذكر اسم المتحدث قبل عبارته لتوجيه الفقاعة إليه. ويمكن تخصيص مشهد واحد، أو لقطتين، أو ثلاث، أو شبكة من أربع لقطات، أو توزيع خاص بكل صفحة مع ترتيب عربي.

**تقليل عدد الصفحات يخفي الصفحات الزائدة مع الاحتفاظ بها في المشروع**؛ ارفع العدد لإظهارها مجددًا. استخدم زر الحذف عند الرغبة في حذف محتوى صفحة، واحتفظ بنسخة JSON قبل تغييرات كبيرة.

## القصص الجاهزة والقوالب

| القصة المدمجة | الموضوع |
| --- | --- |
| سرّ الحظيرة الفارغة | حيوانات المزرعة وفوائدها وصفاتها |
| نصف التفاحة | نصف الكل والأجزاء المتساوية |
| جسر التعاون | توزيع الأدوار والاستماع والعمل الجماعي |
| رحلة قطرة | التبخر والتكاثف والهطول بصورة مبسطة |

هذه أمثلة قابلة للتعديل. تحميل مثال يستبدل المشروع الحالي بعد التأكيد عند وجود محتوى؛ نزّل عملك قبل الاستبدال.

من **قوالبي** يمكنك حفظ المشروع باسم قالب، وفتح القوالب، وتصدير المكتبة أو القوالب المحددة، واستيراد مكتبة، وحذف المحدد. عند استيراد قالب مختلف يحمل اسمًا موجودًا، تضيف الأداة اسمًا مرقّمًا بدل الكتابة فوقه، وتتجاوز القوالب المطابقة تمامًا.

## العربية وRTL والتشكيل

- اتجاه الواجهة عربي، مع تعليمات لترتيب القراءة واللقطات والفقاعات من اليمين إلى اليسار.
- خيارات لحماية اتصال الحروف ومنع عكس النص والحروف الوهمية وكسر الكلمات، وتفضيل مساحة فارغة إذا تعذرت الكتابة الدقيقة.
- أنماط أرقام إنجليزية أو هندية شرقية أو تلقائية حسب السياق.
- تشكيل كامل للنصوص المقروءة، أو الحفاظ على التشكيل المُدخل، أو تشكيل الكلمات المستهدفة، أو عدم إضافة تشكيل.
- أوصاف فنية عربية بالكامل، أو مختلطة، أو إنجليزية بصرية مع قواعد عربية. اختيار اللغة يغيّر صياغة التوجيه الفني، ولا يترجم النص الحر تلقائيًا.
- مواضع متعددة للسرد، وفقاعات حوار، وخيار صور بلا نص مع مساحة لإضافته لاحقًا. في وضع الصور بلا نص، تطلب البرومبتات أيضًا عدم طباعة العناوين والترقيم والتذييل.

لتضمين إرشاد لا ينبغي طباعته، استخدم `//إرشاد//` أو `[[إرشاد]]` داخل الحقول النصية، مثل:

</div>

```text
//اجعل العبارة في بطاقة واضحة أسفل الرسم// تعلّمنا أن التعاون يساعدنا.
```

<div dir="rtl" lang="ar">

يفصل المولد الإرشاد عن النص الظاهر. راجع البرومبت الناتج قبل استخدامه، خصوصًا عند الجمع بين الإرشادات والنصوص الحرفية.

التشكيل والتدقيق وحماية النص المنقول تعليمات للمساعد وأداة الصور، وليست تدقيقًا لغويًا آليًا مضمونًا. راجع النصوص التعليمية والآيات والأحاديث والاقتباسات من مصادرها المعتمدة، وأضف الكتابة بأداة تصميم عند تعذر توليدها بدقة.

## إعداد الصور والدفعات والأغلفة

المقاسات المتاحة: A4 عرضي وعمودي، وA5 عمودي، و16:9، و4:5، ومربع 1:1، و9:16. تتوفر إعدادات للألوان والإضاءة وزاوية المشهد والخلفية والهوامش والطباعة الملونة أو بالأبيض والأسود والدقة المستهدفة.

يمكن طلب القصة كاملة مع تنفيذها على دفعات، أو تحديد بداية الدفعة وحجمها حتى **10 صفحات**، أو طلب أحد الغلافين وحده. كل صفحة مطلوبة صورة مستقلة، ولا يدخل الغلاف ضمن عدد صفحات المحتوى. راعِ قدرة أداة الصور على عدد المخرجات؛ حجم الدفعة إعداد للبرومبت ولا يضمن تنفيذ الخدمة لكل الصور في طلب واحد.

يمكن إضافة عنوان فرعي للغلاف ونص للغلاف الخلفي، وتذييل يدوي أو مستمد من بيانات المعلم والجهة والتاريخ. حدد ظهوره على الغلاف والصفحات، أو الصفحات فقط، أو الغلاف الأمامي فقط، أو الصفحة الأخيرة.

اختيار أسلوب رسوم ثلاثية الأبعاد يعني طلب **صور بمظهر 3D**؛ لا ينتج ملفات نماذج هندسية. كما أن اختيار A4 أو طلب 300 نقطة لكل بوصة لا يضمن أبعادًا فعلية أو دقة طباعة محددة من الخدمة الخارجية؛ تحقق من الملف الناتج.

## استيراد رد المساعد

الأفضل استخدام **طلب كتابة القصة** الذي يولده المشروع؛ فهو يحدد تنسيقًا مناسبًا للاستيراد. يمكن تفعيل طلب JSON، ثم لصق الرد كاملًا في **استيراد رد الذكاء**.

للنص المنظم، استخدم عناوين واضحة مثل `[عنوان القصة]` و`[الفكرة]` و`[الشخصيات]` و`[الصفحات]`، وصفحات مرقمة بالحقول التالية:

</div>

```text
[عنوان القصة]
جسر التعاون

[الشخصيات]
الاسم: عمر | الدور: يخطط للجسر | الهيئة: شعر أسود قصير | الملابس: قميص أزرق

[الصفحات]
الصفحة ١:
العنوان: نبدأ معًا
المشهد: طفلان أمام طاولة عليها مكعبات.
السرد: قرر الطفلان أن يصنعا جسرًا.
الحوار: عمر: لنجرب معًا.
الشخصيات: عمر
التعلم: التعاون
```

<div dir="rtl" lang="ar">

يدعم الاستيراد JSON صالحًا مباشرة أو داخل كتلة كود. وإذا وجد JSON صالحًا يستخدمه قبل التحليل النصي؛ لذلك يجب أن يكون محتواه مطابقًا لما تريد استيراده. راجع عدد الصفحات والشخصيات والسرد والحوار بعد الاستيراد. البرومبت السريع المستورد نص محفوظ وقد يصبح قديمًا عند تعديل المشروع؛ راجعه أو استخدم البرومبتات المولدة من الإعدادات الحالية.

## الحفظ والخصوصية

- **حفظ المشروع** يخزن البيانات في المتصفح، ويمكن تفعيل الحفظ التلقائي.
- **تنزيل المشروع** يحفظ نسخة JSON تشمل الإعدادات والشخصيات والصفحات. استخدمها لنقل العمل إلى متصفح أو جهاز آخر.
- من **قوالبي** يمكنك استيراد المشروع المحفوظ أو مكتبة القوالب.
- ملفات JSON المستوردة لها حد حجم قدره **5,000,000 بايت**. والرد الملصق في نافذة الاستيراد له حد قدره **5,000,000 حرف**.
- الحفظ المحلي مرتبط بالمتصفح وعنوان الصفحة، وقد يُحذف عند مسح بيانات التصفح؛ التنزيل هو النسخة الاحتياطية المحمولة.
- لا يرسل المولد بياناتك إلى خدمة خارجية. إرسال النصوص والصور إلى مساعد أو خدمة توليد يتم يدويًا ويخضع لسياسة تلك الخدمة.
- قد يحتوي JSON على أسماء ومراجع ونصوص ومعلومات تذييل؛ راجعه قبل مشاركته أو نشره.

## التنبيهات وحدود الأداة

- مؤشر الاكتمال وقائمة المراجعة يساعدان على ملاحظة العناصر الناقصة؛ لا يثبتان صحة القصة لغويًا أو علميًا أو ملاءمتها التعليمية.
- الحد المستهدف للكلمات وزمن القراءة والاتساق والدقة قيود داخل الطلب، وقد لا تلتزم بها الأداة الخارجية بالكامل.
- ثبات الشخصيات يتحسن بالأوصاف الدقيقة والمراجع المعتمدة، لكنه لا يضمن تطابق الرسوم. أرفق المرجع مع كل طلب يحتاجه.
- المصدر المرجعي ليس نصًا يُطبع تلقائيًا، ولا يستنتج المولد معلوماته من عنوانه أو رابطه وحده.
- نقل الصفحات أو استيراد الرد قد يتطلب مراجعة المتحدثين والتسلسل والأسئلة والتذييل.
- بدء قصة جديدة أو فتح قالب أو استيراد مشروع قد يستبدل العمل الحالي؛ نزّل نسخة قبل ذلك.
- إذا رفض المتصفح الوصول إلى الحافظة، استخدم النسخ أو اللصق اليدوي.
